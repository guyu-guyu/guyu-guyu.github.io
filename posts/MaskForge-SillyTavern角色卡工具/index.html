MaskForge — SillyTavern 角色卡生成与编辑工具

发表于 2026-07-29 分类于 项目介绍
SillyTavern 角色卡（V3 schema）生成、修改、编辑工具。作为 Pi Coding Agent 的 skill 发布，提供 PNG 角色卡打包/解包、字段描述、生成与校验脚本。

项目简介

MaskForge 是一个 SillyTavern 角色卡（Character Card V3 schema）生成、修改、编辑工具。它作为 Pi Coding Agent 的 skill 发布，让你可以用自然语言驱动 AI 来创建和编辑角色卡。

  • 仓库地址：https://github.com/guyu-guyu/MaskForge
  • 主要语言：JavaScript
  • Skill 名称：maskforge

为什么做这个

SillyTavern 是流行的 AI 角色扮演前端，角色卡是它的核心载体。但手写角色卡有几个痛点：

  • 角色卡是 PNG 图片 + 嵌入 JSON 元数据 的特殊格式，纯文本编辑器没法直接操作
  • V3 schema 字段繁多（描述、人设、对话示例、世界观、扩展字段……），手写容易出错
  • 想批量生成或修改角色卡时，没有趁手的工具链

MaskForge 把角色卡的创建/编辑做成 Pi 的 skill，让 AI 理解 schema、按规范生成、并打包成可导入 SillyTavern 的 PNG 文件。

项目结构

核心能力

PNG 角色卡操作

SillyTavern 的角色卡是 PNG 图片，角色数据以 PNG tEXt chunk 的形式嵌入。MaskForge 提供三个脚本来操作这套格式：

  • pack.js — 把角色 JSON 元数据打包进 PNG 图片，生成可导入 SillyTavern 的角色卡
  • unpack.js — 从 PNG 角色卡提取出 JSON 元数据，便于查看和修改
  • cover.js — 替换或修改角色卡的 PNG 封面图

底层依赖 png-chunks-encode / png-chunks-extract / png-chunks-parse 系列库来读写 PNG chunk。

Schema 驱动的生成与校验

  • describe.js — 描述 SillyTavern V3 schema 的字段含义，帮助 AI 理解每个字段该填什么
  • generate.js — 按 schema 生成角色卡 JSON
  • validate.js — 校验生成的角色卡是否符合 V3 schema

支持用简写名引用 schema（如 v3、character），不必记完整文件路径。

字段速查手册

references/schema-guide.md 是一份字段速查手册，写角色卡时不用反复翻 SillyTavern 的官方文档。

使用方式

MaskForge 是 Pi 的 skill，装上之后 Pi 就能用自然语言驱动它。典型场景：

  • “帮我生成一个赛博朋克侦探角色卡”
  • “把这个角色卡的描述改得更口语化”
  • “从这张 PNG 提取角色数据，把人设字段翻译成英文”
  • “校验这个角色卡是否符合 V3 schema”

底层调用的是上面那些脚本，AI 负责理解意图和填字段。
