scheduleCenter — Windows 定时任务管理中心

发表于 2026-07-29 分类于 项目介绍
Windows 平台定时任务管理中间件，WPF GUI + CLI 双模式，对 Windows 任务计划程序做受控封装，只管理自己创建的任务，提供 JSON 输出供其他程序调用。

项目简介

scheduleCenter 是一个 Windows 任务计划程序的管理中间件，提供 WPF GUI 管理界面 + CLI 模式 两种使用方式。其他程序/脚本可以通过命令行调用它来增删改查 Windows 定时任务，并获得结构化的 JSON 输出。

  • 仓库地址：https://github.com/guyu-guyu/scheduleCenter
  • 主要语言：C# / .NET Framework 4.8
  • 平台：Windows 10/11

设计思路

Windows 自带的任务计划程序功能强大但操作繁琐，命令行工具 schtasks 又不够友好。scheduleCenter 想做的是一层 受控封装：

  • 单 exe 双模式 — 无参数启动 WPF GUI；带参数进入 CLI 模式（JSON 输出 + 退出码）
  • 文件夹隔离 — 所有任务都创建在 \ScheduleCenter\ 文件夹下；系统内置任务不可见、不可操作
  • 管理员权限 — 清单声明 requireAdministrator，支持 SYSTEM 账户 / 最高权限任务
  • 零依赖部署 — .NET Framework 4.8 随 Windows 10/11 自带，无需额外安装运行时

这个工具不管理所有 Windows 计划任务——它只管理通过本工具创建的任务（位于 \ScheduleCenter\ 文件夹下）。用户在 Windows 自带的「任务计划程序」里仍然能看到这些任务，这是预期行为。

功能特性

V1 基础功能

  • 任务的增删改查、启用/禁用、立即运行
  • 6 种基础触发器：一次性、每日、每周、每月、启动时、登录时
  • 运行历史查看（来源：Microsoft-Windows-TaskScheduler/Operational 事件日志）
  • GUI 三栏布局：文件夹树 + 任务列表 + 历史标签页（失败事件红色高亮、可筛选）
  • 「复制等价 CLI 命令」功能（GUI 操作 → 剪贴板 CLI 命令）
  • 统一错误模型（TaskServiceException + ErrorCode 枚举）

V2 高级功能

  • 多触发器组合 — 一个任务可以挂多个触发器（V1 只支持单触发器）
  • 空闲触发器 — 系统空闲时触发
  • 事件触发器 — 基于 Windows 事件日志，支持简化参数（日志名/源/事件 ID）或完整 XPath 订阅
  • 高级条件：
    • 执行时间限制（ExecutionTimeLimit）
    • 使用电池时不启动（DisallowStartIfOnBatteries）
    • 切换到电池时停止任务（StopIfGoingOnBatteries）
  • 任务 XML 导入/导出 — 基于任务计划程序原生 TaskDefinition.XmlText，单任务粒度

CLI 用法

子命令一览

命令 说明
add 添加新任务
update 更新已有任务（仅修改提供的字段）
delete 删除任务（--force 跳过确认）
get 获取任务详情
list 列出任务（--filter 通配匹配）
enable / disable 启用/禁用任务
run 立即运行任务
history 查看运行历史（--last <N>、--errors-only）
export / import 任务 XML 导出/导入
help / h 显示人类友好的完整帮助
manifest 输出机器可读的 CLI manifest JSON（给 Agent 用）

所有 --name 都相对于 \ScheduleCenter\，支持子文件夹路径（如 --name "MyApp\Backup"）。

与其他项目的配合

scheduleCenter 是为给其他程序提供定时任务服务而设计的。比如 AutoVideoCompressor-视频素材定时压缩工具 的 --run-once 模式就可以交给 scheduleCenter 来定时调度，避免每个工具自己实现一套调度逻辑。
