novelForgePi — 把 Pi 改造成小说写作工具

2026-07-29
项目介绍-TypeScriptObsidianPiAI写作小说

项目简介

novelForgePi 把 Pi Coding Agent 改造为中文网文写作辅助工具。它是一组 Pi 的扩展（packages + skills + slash commands），装上之后 Pi 就能帮你开新书、规划大纲、写场景、做一致性审计。

  • 仓库地址：https://github.com/guyu-guyu/novelForgePi
  • 主要语言：TypeScript
  • 安装方式：pi install git:github.com/guyu-guyu/novelForgePi

为什么做这个

通用 AI Coding Agent 写小说有几个痛点：

  • 不知道怎么组织一本长篇小说的文件结构
  • 没有章节、场景、设定集这些概念
  • 写长文容易人设崩坏、前后矛盾
  • 写出来的东西一股「AI 翻译腔」

novelForgePi 想解决的就是这些问题——给 Pi 一套写作领域的原子工具和技能，让它像个懂网文的助手一样工作。

快速开始

概览

  • 32 个原子文件工具（scene / chapter / codex / character / outline / ctx / stats）
  • 8 个写作技能（scene-writing / polishing、consistency-audit、outline-planning、character-*、codex-management、prompt-pack-generator）
  • 19 个斜杠命令模板
  • 内置 cn-webnovel 题材包（风格总纲 + 续写/润色指令 + 一致性规则 + 示例片段）
  • Obsidian 兼容：YAML frontmatter + [[wiki-links]] + 全局唯一文件名
  • 16 个测试（单元 + 集成）通过

设计思路

原子工具而非大命令

没有把「写一章小说」做成一个大命令，而是拆成 32 个原子文件工具（创建场景、读取章节、更新设定集……）。这样可以灵活组合，也让 Agent 的每一步操作都可观察、可干预。

Obsidian 兼容

所有文件都用 YAML frontmatter + [[wiki-links]]，文件名全局唯一。这意味着你可以直接用 Obsidian 打开小说项目，双链在 Obsidian 里照样能跳转，传统笔记工作流和 AI 写作工作流可以无缝衔接。

题材包机制

内置的 cn-webnovel 题材包是一组可替换的「风格总纲 + 续写/润色指令 + 一致性规则 + 示例片段」。不同题材（玄幻、都市、科幻……）可以做成不同的题材包，切换题材不用改工具本身。

一致性审计

consistency-audit 技能会扫描已写的章节，对照设定集（角色、世界观、物品）找出前后矛盾的地方。长篇小说写到 50 万字的时候，这个功能救命。

与 pi-isolate 的配合

novelForgePi 的 /new-book 命令会在书项目里建好 .pi-isolated/ 并 symlink novelForgePi 包，然后提示你退出 pi 跑 pi-isolate-以隔离模式运行pi的命令。两者职责分离：

工具 职责
pi-isolate 通用隔离启动：symlink 凭证 + 生成 settings.json + exec pi
novelForgePi /new-book novelForgePi 特有：建书骨架 + symlink novelForgePi 包到 .pi-isolated/git/...

这样每本小说都是一个独立的隔离环境，互不污染。
