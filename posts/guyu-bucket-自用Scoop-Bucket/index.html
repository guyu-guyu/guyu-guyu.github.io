guyu-bucket — 自用 Scoop Bucket

2026-07-29
项目介绍-ScoopWindows包管理CLI

项目简介

guyu-bucket 是我个人维护的 Scoop bucket，收录我自己维护和常用的应用清单（manifest）。

  • 仓库地址：https://github.com/guyu-guyu/guyu-bucket

为什么做这个

Scoop 是 Windows 上流行的命令行包管理器，主打便携、用户级安装、不污染系统。它用 “bucket”（仓库）来组织应用清单——你可以把它理解成类似 Homebrew 的 tap。

我自己写的桌面工具如果要手动分发安装包，用户得自己去 Releases 页面下载、解压、放目录、加 PATH，体验很差。把它们做成 Scoop manifest 之后，用户一条命令就能装好：

升级也是一条命令：scoop update autovideocompressor。

使用方法

目录结构

每个应用对应 bucket/ 下的一个 JSON manifest 文件，定义下载地址、校验值、安装方式、环境变量等。

收录的应用

应用 描述 版本
autovideocompressor 视频素材定时压缩工具 — 自动扫描目录、调用 ffmpeg 压缩、支持 Per-directory 配置和 cron 调度 0.2.1
schedulecenter Windows 定时任务管理中心 — WPF GUI + CLI 双模式，管理 Windows 任务计划程序 0.1.1

详细介绍可以看各自的项目介绍文：

  • AutoVideoCompressor-视频素材定时压缩工具
  • scheduleCenter-Windows定时任务管理中心

与自研工具的协同

这个 bucket 主要是给我自己发布的桌面工具做分发渠道。流程大致是：

  1. 在 AutoVideoCompressor-视频素材定时压缩工具 或 scheduleCenter-Windows定时任务管理中心 仓库打 tag、发 Release
  2. 在 guyu-bucket 更新对应 manifest 的版本号、下载 URL、hash
  3. 用户 scoop update 后就能拉到新版本
