guyu-skills — 我的 Pi 技能集合

发表于 2026-07-29 分类于 项目介绍
个人维护的 Pi Coding Agent skill 集合，目前收录 MaskForge（SillyTavern 角色卡生成/编辑技能）。作为 skill 的统一发布仓库。

项目简介

guyu-skills 是我个人维护的 Pi Coding Agent skill 集合，作为各种 skill 的统一发布仓库。

  • 仓库地址：https://github.com/guyu-guyu/guyu-skills
  • 主要语言：JavaScript
  • 当前收录：MaskForge-SillyTavern角色卡工具

为什么单独建一个仓库

Pi 的 skill 可以单独发布成仓库，也可以集中到一个 “skills 集合” 仓库里。单独建一个 guyu-skills 仓库有几个好处：

  • 统一入口 —— 别人（或未来的我）想装我所有的 skill，只要知道这一个仓库地址
  • 降低开销 —— 每个 skill 单独建仓库要有 README、CI、release 配置，小 skill 没必要
  • 版本同步 —— 多个 skill 之间若有共享约定（命名、目录结构），放一起更容易保持一致

与其他项目的关系

guyu-skills 里的 skill 可以配合 pi-isolate-以隔离模式运行pi的命令 使用——在隔离环境里按需 --add-skill 把某个 skill 从全局拣选到当前项目，保持项目环境的纯净。
