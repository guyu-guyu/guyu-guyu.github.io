AutoVideoCompressor — 视频素材定时压缩工具

2026-07-29
项目介绍-TauriRustVueffmpeg视频压缩桌面工具

项目简介

AutoVideoCompressor 是一个基于 Tauri 2 + Rust + Vue 3 的 Windows 视频压缩桌面工具。它会自动扫描指定目录下的视频文件，调用 ffmpeg 进行压缩，并保留更小的文件。

简单来说：你给它一堆目录，它每天定时帮你把里面的视频压得更小，省下硬盘空间。

  • 仓库地址：https://github.com/guyu-guyu/AutoVideoCompressor
  • 主要语言：Rust（业务逻辑全部在 Rust 层）
  • 平台：Windows 10/11 (x64)

为什么做这个

平时攒的视频素材越来越多，手动一个个用 ffmpeg 压缩太累人。市面上的工具要么不支持定时，要么不能按目录配置不同策略，于是自己写了一个。

核心功能

  • Per-directory 独立配置 — 每个目录有独立的 include/exclude 规则、过滤器、重命名规则、调度时间
  • Cron 定时调度 — 每天指定时间自动压缩，严格不补跑
  • 串行执行 — 同一时间只压缩一个目录，完成后自动处理队列中的下一个
  • 实时进度推送 — 逐文件压缩进度，支持手动停止
  • 循环压缩检测 — 自动识别重命名后再次匹配的白名单文件，标记风险
  • 全局参数模板 — 可自定义 H.265/H.264 预设模板，按目录选用或自定义
  • 单次压缩总大小限制 — 按文件顺序累计，超出部分自动跳过并在预览中标注
  • 压缩历史日志 — 人类可读文本 + 机器可读 JSON 块，保留天数可配
  • 压缩文件预览 — 显示匹配文件、压缩后文件名、大小、循环风险、单次限制状态
  • 系统托盘常驻 — 最小化到托盘、右键菜单（显示主窗口 / 退出）
  • 开机自启动
  • --run-once 模式 — 无窗口单次执行，供 Windows 任务计划程序调用

技术栈

层级 技术
框架 Tauri 2.x
后端 Rust（业务逻辑全部在 Rust 层）
前端 Vue 3 + TypeScript + Vite
UI 库 Naive UI
平台 Windows 10/11 (x64)

业务逻辑全部放在 Rust 层是刻意的选择——压缩是 CPU 密集型任务，放在 Rust 里既快又稳，前端只负责展示和交互。

安装

从 Releases 下载最新版：

  • AutoCompress_x.x.x_x64-setup.exe — NSIS 安装程序（推荐）
  • autocompress.exe — 便携版，无需安装

依赖：需安装 ffmpeg，可以在 PATH 中使用，或在全局设置中指定路径。

命名说明

项目名称为 AutoVideoCompressor。代码内部的包名（autocompress）、产品显示名（AutoCompress）、配置目录（%APPDATA%/AutoCompress）等都是历史遗留的内部标识符，与实际代码保持一致，不代表项目名称变更。
