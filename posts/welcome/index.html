欢迎来到谷雨的博客

发表于 2026-07-27 分类于 关于
博客首次上线，使用 Hexo + NexT + Obsidian + GitHub Actions 搭建。

欢迎

这是谷雨的博客，使用以下技术栈搭建：

  • Hexo — 静态站点生成器
  • NexT — 主题
  • Obsidian — 笔记编辑器（用 双链语法 串联笔记）
  • GitHub Actions — 自动部署

关于双链

本博客支持 Obsidian 的双链语法，可以在文章间相互引用。详见 obsidian-syntax-demo。

关于本站

这是一个还在搭建中的博客，更多内容会陆续添加。
